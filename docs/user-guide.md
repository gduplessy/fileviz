# User guide

Select a drive or folder, then start a scan. Administrator scans enable raw NTFS access and protected-folder enumeration. Network shares use directory enumeration and your existing Windows credentials.

Name matches are candidates only. Content duplicate results require full hashes. Review keeper and removal selections before cleanup. Quarantine and the Recycle Bin retain data and do not immediately free space.

Incomplete, cancelled, and stale snapshots must not be interpreted as complete inventories. Review diagnostics for denied access, offline files, and unsupported metadata.
